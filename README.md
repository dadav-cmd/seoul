# 大谷マップinSeoul

ソウル特別市25区の、建築家・アーティストの設計による施設や、カフェ・飲食店・ショップ・公園・公共施設を地図で探す個人用マップ。画面は日本語で、施設名には韓国語の原表記を併記している。273件を収録（2026-10-20時点）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面と動作（東京版と同じ仕組み） |
| `data/spots.json` | サイトが読み込むスポットのデータ（`tools/build_data.py` で生成） |
| `data/src/*.psv` | スポットの元データ（`|` 区切り） |
| `data/ledger.csv` | 台帳（Google スプレッドシート）に貼り付けるための書き出し |
| `data/wards.json` | 25区の区境と漢江の中心線（claude.ai 上のプレビュー用） |
| `vendor/` | Leaflet 1.9.4 と Leaflet.markercluster 1.5.3（同梱） |

## 東京版との違い

- 地図は OpenStreetMap のタイル（API キー不要）。標準は淡色表示（CSS で彩度を落としたもの）で、右上の切替でカラー表示にできる。CARTO は API キーが必要になったため使わない。国土地理院の地図は韓国を含まないため使わない。
- 詳細画面の経路ボタンは「NAVER地図」「KakaoMap」「Googleマップ（電車）」の3つ。韓国では Google マップの徒歩・車の経路案内が使えないため、現地の2アプリを主に使う。いずれも韓国語の施設名で検索する。
- 「韓国語名をコピー」ボタンで、タクシーや現地アプリの検索に施設名を使える。
- 「観光客におすすめ」タグ（121件）と、その絞り込みを追加。一覧では「観光」の印を付ける。
- 位置はすべて目安（`approx: true`）。座標は記載の区の中にあることを区境データで確認している。

## GitHub Pages での公開手順

東京版と同じ。新しいリポジトリ（例：`seoul-design-map`、Public）を作り、このフォルダの中身をアップロードして、Settings → Pages で `main` / `/ (root)` を指定する。

## 収録データの状態

| 区分 | 件数 |
| --- | --- |
| 建築・アート | 122 |
| カフェ・飲食 | 46 |
| ショップ | 45 |
| 公園・庭園 | 41 |
| 公共施設 | 19 |

- `status: "checked"`（16件）はウェブで開館・所在を確認済み。
- `status: "unverified"` は未確認。詳細画面に「公式情報でご確認ください」と表示する。
- 休館日 `closedDays` が null のものは「未確認」と表示する。韓国の宮殿・博物館は月曜または火曜が休みのことが多い。
